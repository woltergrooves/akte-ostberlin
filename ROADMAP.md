# Roadmap

We werken in fases. Elke fase krijgt een eigen branch (`fase-N`) en wordt daarna samengevoegd in `main`. `main` is altijd speelbaar.

## ✅ Fase 1: Korter, simpeler, moderner (nu)

- [x] Speelduur ingekort: van 31 naar 15 beurten (voorjaar, zomer, herfst)
- [x] Minder meters: Gunst, Geweten, Verdenking (Onrust en Gezin werken op de achtergrond)
- [x] Minder acties: observeren, werven, waarschuwen, arresteren en microfoons (postcontrole, telefoontap, Zersetzung en geurmonsters eruit)
- [x] Werven met één knop, met de kans in procenten
- [x] Resultaten als korte melding in plaats van een pop-up per actie
- [x] Kortere uitleg (3 kaarten) en een kort beurtoverzicht
- [x] Moderne interface: donker, afgeronde kaarten, zwevende navigatie met iconen
- [x] PS2-graphics: rendering op lage resolutie (±460p), 15-bit kleur met ordered dither, Lambert-shading met facetten, pixelige texturen, harde schaduwen, low-poly mensen met lopende benen
- [x] Op GitHub gezet

## Fase 2: De wijk leeft

- [ ] Bewoners lopen echt rond als personages. Tik op iemand op straat om het dossier te openen.
- [ ] Gebouwen tonen wat je weet (microfoons, informanten, verdachten)
- [ ] Dag en nacht per beurt, straatverlichting
- [ ] Inzoomen op een gebouw met een korte camerarit

## Fase 3: Geluid en sfeer

- [ ] Geluid: typemachine, telefoon, radio, regen, straat
- [ ] Muziek per jaar (1985 kil, 1989 opwindend)
- [ ] Trillen bij belangrijke momenten (iPhone)
